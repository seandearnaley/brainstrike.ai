The repository is a pnpm workspace: one app, [`apps/desktop`](https://github.com/seandearnaley/brainstrike/tree/main/apps/desktop), and 42 packages under [`packages/`](https://github.com/seandearnaley/brainstrike/tree/main/packages). Every package is consumed as TypeScript source through its `exports`. None is built to a `dist` folder except the two native add-ons and two test tools.

## The layers

<Diagram
  code={packages}
  caption="The main packages and the direction they depend in. Each box opens its folder."
/>

The rule the picture shows: **interface packages and host packages never import each other.** They meet at the contract packages, and at run time they talk over a message port. `apps/desktop` is the only place that composes both sides.

That boundary is why the host can run without Electron, and why host code is tested as plain Node.

### Interface

| Package | What it owns |
| --- | --- |
| [`app-shell`](https://github.com/seandearnaley/brainstrike/tree/main/packages/app-shell) | React layout and feature composition for the app. It wires the interface to capabilities passed in; it is not a second runtime or storage owner. |

| [`file-explorer-ui`](https://github.com/seandearnaley/brainstrike/tree/main/packages/file-explorer-ui) | Explorer composition, tree grid, file tabs and token status. |
| [`file-explorer`](https://github.com/seandearnaley/brainstrike/tree/main/packages/file-explorer) | Explorer state and actions, independent of any interface. |
| [`file-explorer-hooks`](https://github.com/seandearnaley/brainstrike/tree/main/packages/file-explorer-hooks) | React hooks for filesystem access, selection, loading and watcher health. |
| [`workspace-search`](https://github.com/seandearnaley/brainstrike/tree/main/packages/workspace-search) | The Explorer's Search tab: live text search over the workspace. |
| [`settings-ui`](https://github.com/seandearnaley/brainstrike/tree/main/packages/settings-ui) | Settings and status screens. |
| [`mcp-app-host-ui`](https://github.com/seandearnaley/brainstrike/tree/main/packages/mcp-app-host-ui) | The renderer surface that hosts MCP Apps. |
| [`ui`](https://github.com/seandearnaley/brainstrike/tree/main/packages/ui) | Shared components: shadcn and Radix primitives, tree table, tab strip, Markdown, code and diagram surfaces, theme assets. |
| [`hooks`](https://github.com/seandearnaley/brainstrike/tree/main/packages/hooks) | Small shared React hooks. |
| [`context-actions`](https://github.com/seandearnaley/brainstrike/tree/main/packages/context-actions) | The headless context action system: targets, actions, a registry and capability gating. |

### Interface state

| Package | What it owns |
| --- | --- |

| [`storage`](https://github.com/seandearnaley/brainstrike/tree/main/packages/storage) | The renderer's own durable stores. Separate from the host's state database and the run log. |
| [`token-cache`](https://github.com/seandearnaley/brainstrike/tree/main/packages/token-cache) | A persistent token-count cache with a background worker, for the Explorer. |

| [`worker-runtime`](https://github.com/seandearnaley/brainstrike/tree/main/packages/worker-runtime) | Shared worker plumbing used by the two workers above. |
